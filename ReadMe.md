## Simluacro DI Examen 02
### Configuación de Riego
Se debe de realizar un select para cambiar de card según el valor del mismo, siendo Zoa 1, Zoa 2, Zoa 3.

### Zoa 1
Se tendrá un Checkbox (Activar Zona), donde todo en esta card estará desactivado hasta que se de al check

Un Campo de Descripción de la residencia donde se regará. 

Un radiobutton donde se escogerá si se riega semanalmente o diariamente

Un comboBox donde estarán checkbox de los días, el cual solo se activará en caso de que el radiobutton esté en diario.

### Zoa 2
Un texto grande donde se añadirán las líneas de descripción de la zoa1

### Zoa 3
Una tabla de 3x5, los sí o no serán checkbox

| DNI | Nombre | Vivo |

| 34567890B | Fos | No |
